# YouTube Downloader (Django)

Shkarkues YouTube me ndërfaqe web në Django — ngjit linkun dhe shkarko videon.

`Python` `Django` `pytube`

## 🚀 Live Demo
Hape **`index.html`** në browser — demo-ja ekzekutohet direkt, pa instalime.
Nëse repo është publikuar me GitHub Pages: `https://erionnezha.github.io/YouTube-Downloader-Django/`

## 📝 Kodi Burim
Kodi i plotë është në dosjen [`original/`](original/) dhe shfaqet krahas demo-s live në `index.html`.

## ▶️ Ekzekutimi origjinal
`pip install -r requirements.txt`, `python manage.py migrate`, `python manage.py runserver`.
